# Exercícios em Java

Este repositório contém exercícios desenvolvidos durante meus estudos de programação em Java no curso de Sistemas de Informação na UFLA.

## Conteúdo

Os exercícios abordam conceitos básicos de programação, como:

- Estruturas condicionais (if/else)
- Laços de repetição
- Entrada e saída de dados
- Lógica de programação

## Arquivos

- ex1.java
- ex2.java
- ex3.java

## Objetivo

Praticar lógica de programação e desenvolver uma base sólida em Java para o aprendizado de estruturas de dados e desenvolvimento de software.
